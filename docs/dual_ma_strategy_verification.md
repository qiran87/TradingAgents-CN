## 技术细节

### 死叉判断公式

```python
# app/strategies/dual_ma.py:106-112
if prev_short_ma >= prev_long_ma and short_ma < long_ma:
    if position > 0:  # 有持仓
        return {
            "action": "sell",
            "amount": position,
            "reason": f"死叉: 短期均线({short_ma:.2f})下穿长期均线({long_ma:.2f})"
        }
```

### 数据要求

- **最少需要**: 21天数据 (long_window + 1)
- **原因**: 需要计算当天和前一天的MA20,所以需要21个价格

### 实际案例

**2025-07-21死叉详情**:

```
价格历史: [10.0, 10.05, ..., 14.6, 13.8, 13.5]  # 143个价格

前一天 (第142天):
  MA5 = sum([14.54, 14.56, 14.58, 14.6, 13.8]) / 5 = 14.56
  MA20 = sum(第123-142天的价格) / 20 = 14.41

当天 (第143天):
  MA5 = sum([14.56, 14.58, 14.6, 13.8, 13.5]) / 5 = 14.21
  MA20 = sum(第124-143天的价格) / 20 = 14.35

判断:
  prev_ma5 (14.56) >= prev_ma20 (14.41) ✅
  short_ma (14.21) < long_ma (14.35) ✅
  → 死叉! 卖出!
```

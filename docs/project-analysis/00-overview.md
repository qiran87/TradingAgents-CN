# TradingAgents-CN 项目概述

## 项目简介

TradingAgents-CN 是一个基于多智能体和大语言模型的股票分析学习平台，专注于中国股市（A股、港股、美股）的分析和回测。该项目采用现代化的前后端分离架构，提供了完整的股票数据分析、回测交易、多智能体分析等功能。

## 核心定位

- **股票分析学习平台**：提供专业的技术分析和基本面分析工具
- **策略回测系统**：支持多种技术指标的策略回测和验证
- **多智能体分析**：基于 LangGraph 构建的智能分析团队
- **多市场支持**：覆盖 A股、港股、美股三大市场

## 技术架构

### 后端技术栈

```
核心框架: FastAPI (异步 Python Web 框架)
数据库: MongoDB (文档存储) + Redis (缓存/队列)
数据源: Tushare、AKShare、BaoStock
异步处理: Motor (MongoDB 异步驱动)
智能体: LangGraph (多智能体编排)
认证: JWT (基于 Token 的身份验证)
```

### 前端技术栈

```
框架: Vue 3 (Composition API)
语言: TypeScript
构建工具: Vite
UI 框架: Element Plus
状态管理: Pinia
图表库: ECharts (可视化)
路由: Vue Router
HTTP 客户端: Axios
```

## 核心功能模块

### 1. 回测引擎

回测引擎是项目的核心功能之一，提供完整的策略回测能力：

- **策略系统**：支持双均线、MACD、RSI、布林带等技术指标策略
- **策略注册机制**：通过 `StrategyRegistry` 统一管理所有策略
- **回测执行**：基于 `BacktestEngine` 的完整回测流程
- **T+1 规则**：严格执行中国股市的 T+1 交易规则
- **交易费用**：真实计算佣金、印花税、过户费等成本
- **实时进度**：通过 WebSocket 推送回测进度和持仓变化

### 2. 多智能体分析系统

基于 LangGraph 构建的智能分析团队：

- **市场分析师**：技术面分析
- **基本面分析师**：财务数据解读
- **新闻分析师**：新闻情绪分析
- **社交媒体分析师**：舆情监控
- **中国股市分析师**：A股特色分析
- **风险管理师**：风险评估
- **交易员**：交易决策

### 3. 数据服务层

多数据源统一管理：

- **优先级系统**：AKShare > BaoStock > Tushare（可配置）
- **自动降级**：主数据源失败时自动切换
- **缓存机制**：Redis + MongoDB 二级缓存
- **定时同步**：基于 APScheduler 的数据同步任务

### 4. 用户系统

完整的用户管理：

- **JWT 认证**：基于 Token 的无状态认证
- **RBAC 权限**：角色基础的访问控制
- **操作日志**：完整的用户操作审计
- **使用统计**：资源使用情况监控

## 设计原则

### 1. 回测框架设计

- **策略抽象**：所有策略继承自 `BaseStrategy`，统一接口
- **参数化设计**：策略参数可配置、可验证
- **状态隔离**：每个回测任务独立的 `BacktestState`
- **可扩展性**：通过注册机制轻松添加新策略

### 2. 代码规范

- **异步优先**：所有数据库操作使用异步（Motor）
- **依赖注入**：通过 FastAPI 的 Depends 实现依赖注入
- **统一响应**：使用 `ok()` 和 `error()` 标准化响应
- **错误处理**：自定义异常类，清晰错误信息

### 3. 数据管理

- **日期格式**：统一使用 `YYYY-MM-DD` 字符串
- **中文本地化**：所有面向用户的文本使用中文
- **缓存策略**：Redis 缓存 + MongoDB 持久化
- **数据验证**：Pydantic 模型严格验证输入

## 核心特点

### 1. 真实交易模拟

- **T+1 规则**：买入当日不可卖出
- **交易费用**：佣金（万分之2.5）、印花税（千分之一卖出）、过户费（万分之0.2）
- **最小单位**：100股倍数交易
- **资金管理**：精确计算可用资金和持仓成本

### 2. 实时反馈

- **WebSocket 推送**：回测进度、交易信号、持仓变化
- **SSE 备用**：服务器推送事件作为 WebSocket 的补充
- **HTTP 轮询**：最兼容的状态查询方式

### 3. 多数据源容错

- **自动降级**：主数据源失败时切换备用源
- **优先级配置**：数据库中可配置数据源优先级
- **缓存优化**：减少对外部 API 的依赖

### 4. 可扩展架构

- **策略插件化**：新策略只需继承基类并注册
- **智能体模块化**：独立的分析师模块
- **API 分层**：清晰的服务层和路由层划分

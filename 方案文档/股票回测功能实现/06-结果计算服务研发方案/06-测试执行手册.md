# 06-结果计算服务测试手册

## 一、测试概述

本测试手册用于验证**回测结果计算服务**的功能正确性，包括：
- 收益指标计算（总收益率、年化收益率、累计收益率等）
- 风险指标计算（最大回撤、波动率、VaR等）
- 风险调整收益指标计算（夏普比率、索提诺比率、卡玛比率）
- 交易统计（胜率、盈亏比等）
- 资金曲线计算
- API端点测试

---

## 二、测试环境准备

### 2.1 系统要求

- **Python**: 3.10+
- **Node.js**: 18.0+
- **MongoDB**: 4.4+
- **Redis**: 6.0+

### 2.2 依赖安装

```bash
# 安装Python依赖
pip install -e .

# 安装测试依赖
pip install pytest pytest-asyncio

# 安装前端依赖
cd frontend
npm install
```

### 2.3 服务启动

**启动后端服务：**
```bash
# 方式1：直接运行
./venv/bin/python3 -m app

# 方式2：使用uvicorn
./venv/bin/uvicorn app:app --reload --host 0.0.0.0 --port 8000
```

**启动前端服务（可选）：**
```bash
cd frontend
npm run dev
```

**启动数据库服务：**
```bash
# MongoDB
brew services start mongodb-community  # macOS
sudo systemctl start mongod            # Linux

# Redis
brew services start redis               # macOS
sudo systemctl start redis             # Linux
```

## 六、故障排查

### 6.1 常见问题

**问题1：数据库连接失败**
```
Error: ServerSelectionTimeoutError
```
**解决方案：**
```bash
# 检查MongoDB是否运行
pgrep mongod

# 启动MongoDB
brew services start mongodb-community  # macOS
sudo systemctl start mongod            # Linux
```

**问题2：单元测试失败**
```
FAILED tests/test_result_calculator.py::test_xxx
```
**解决方案：**
```bash
# 清空测试数据
mongosh mongodb://admin:password@localhost:27017/tradingagents
db.backtest_tasks.deleteMany({"backtest_id": /^test_/})
db.backtest_daily_states.deleteMany({"backtest_id": /^test_/})
db.backtest_trades.deleteMany({"backtest_id": /^test_/})
db.backtest_results.deleteMany({"backtest_id": /^test_/})

# 重新运行测试
python3 -m pytest tests/test_result_calculator.py -v
```

**问题3：回测任务卡住不动**
**解决方案：**
```bash
# 检查后端日志
tail -f logs/app.log

# 检查Redis连接
redis-cli ping

# 手动中断回测
curl -X POST "http://localhost:8000/api/backtest/{backtest_id}/interrupt"
```

**问题4：前端组件无法显示图表**
**解决方案：**
```bash
# 检查echarts是否安装
cd frontend
npm list echarts

# 重新安装echarts（如果缺失）
npm install echarts@5.4.3

# 重启前端服务
npm run dev
```

在 `app/main.py` 的 `lifespan` 函数中添加了策略数据自动初始化逻辑：

**实现位置**: `app/main.py:233-269`

**核心逻辑**:
```python
# 自动初始化策略数据（如果数据库中还没有）
try:

        logger.info("📊 检测到策略数据为空，开始自动初始化...")

        # 创建索引
        # 插入分类
        # 插入策略
        # 记录统计信息
    else:
        # 已有数据，跳过初始化
        logger.info(f"📊 策略数据已存在 ({strategy_count}个策略)，跳过初始化")
except Exception as e:
    logger.warning(f"⚠️  策略数据自动初始化失败: {e}")
```

### 2. 特性说明

#### ✅ 智能检测
- 首次启动时自动检测数据库中是否存在策略数据
- 如果为空，自动执行初始化
- 如果已存在，跳过初始化，避免重复操作

#### ✅ 完整功能
- 自动创建MongoDB索引
- 自动插入策略分类数据（3个分类）
- 自动插入内置策略数据（5个策略）
- 详细的日志输出

#### ✅ 容错机制
- 使用try-except包裹初始化逻辑
- 即使初始化失败，也不影响应用启动
- 提供手动初始化的备选方案

#### ✅ 用户友好
- 清晰的日志提示
- 首次启动显示完整的初始化过程
- 后续启动显示跳过信息

## 🔌 API接口

策略管理接口会在应用启动后立即可用，访问 http://localhost:8000/docs 查看：

**标签**: `backtest-strategies`

**可用接口**:
1. `GET /api/backtest/strategies` - 获取策略列表
   - 支持分类过滤、关键词搜索、排序、分页

2. `GET /api/backtest/strategies/{strategy_id}` - 获取策略详情
   - 返回策略完整信息和参数定义

3. `GET /api/backtest/strategies/categories` - 获取策略分类
   - 返回所有分类及每个分类的策略数量

4. `POST /api/backtest/strategies/{strategy_id}/validate-params` - 校验策略参数
   - 校验参数类型、范围、必填项等

## 🔍 技术细节

### 数据结构
- **策略数据**: 5个内置策略（双均线、布林带、MACD、RSI、KDJ）
- **分类数据**: 3个分类（趋势跟踪、震荡、动量）
- **索引配置**: 策略ID唯一索引、分类唯一索引、复合索引、全文搜索索引

### 安全性
- 不会覆盖已存在的数据
- 使用 `delete_many` 清空后插入，确保数据一致性
- 异常处理确保应用启动不受影响

### 性能
- 仅在首次启动时执行初始化
- 后续启动跳过，无性能影响
- 异步操作，不阻塞应用启动

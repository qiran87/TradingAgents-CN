## 🚀 快速启动步骤

> **重要说明**: 从当前版本开始,策略数据会在应用**首次启动时自动初始化**,无需手动运行初始化脚本!

### 第一步：启动后端服务

应用启动时会自动检测并初始化策略数据:

```bash
# 方式1：使用uvicorn（推荐）
python3 -m uvicorn app.main:app --reload --port 8000

# 方式2：使用FastAPI CLI
pip install fastapi-cli
uvicorn app.main:app --reload --port 8000
```

**启动日志示例**:
```

✅ 已插入 3 个策略分类
✅ 已插入 5 个内置策略
📊 策略初始化完成: 5个策略, 3个分类, 13个参数
💡 策略API已就绪，访问 http://localhost:8000/docs 查看 backtest-strategies 接口
```

**第二次启动**:
```
📊 策略数据已存在 (5个策略)，跳过初始化
```

**验证后端启动**：
- 访问 http://localhost:8000/docs
- 应该看到Swagger API文档

**⚠️ 重要提示：策略接口需要登录认证**

如果看不到 **"backtest-strategies"** 标签组：

1. 点击页面右上角的 🔒 **"Authorize"** 按钮
2. 输入登录信息：
   ```
   用户名: admin
   密码: admin123
   ```
3. 点击 **"Authorize"** 确认
4. 关闭对话框，刷新页面

登录后，**"backtest-strategies"** 标签组会出现，包含以下接口：
  - `GET /api/backtest/strategies` - 获取策略列表
  - `GET /api/backtest/strategies/{strategy_id}` - 获取策略详情
  - `GET /api/backtest/strategies/categories` - 获取策略分类
  - `POST /api/backtest/strategies/{strategy_id}/validate-params` - 校验策略参数

**快速验证**：
```bash
./verify_strategies.sh
```

## 🐛 常见问题排查

### 问题0：motor模块缺失
**错误信息**: `ModuleNotFoundError: No module named 'motor'`

**原因**: Python环境中没有安装motor(异步MongoDB驱动)

**解决方案A - 快速修复**:
```bash
pip3 install 'motor>=3.3.0'
```

**解决方案B - 使用测试模式** (推荐):
```bash
# 使用--dry-run参数,无需安装motor
PYTHONPATH=. python3 -m app.scripts.init_strategies --dry-run
```

### 问题1：页面显示"暂无策略"
**原因**：MongoDB中没有初始化策略数据

**解决**：
```bash
# 方式1: 使用测试模式验证(无需MongoDB)
cd /Users/qiran/LLM_Proj/LS_Proj/zp_ls/TradingAgents-CN
PYTHONPATH=/Users/qiran/LLM_Proj/LS_Proj/zp_ls/TradingAgents-CN python3 -m app.scripts.init_strategies --dry-run

# 方式2: 正常模式初始化(需要MongoDB)
PYTHONPATH=/Users/qiran/LLM_Proj/LS_Proj/zp_ls/TradingAgents-CN python3 -m app.scripts.init_strategies
```

### 问题2：API调用404错误
**原因**：后端服务未启动或路由未注册

**检查**：
1. 确认后端服务已启动（访问 http://localhost:8000/docs）
2. 检查控制台网络请求URL是否正确
3. 检查 `app/main.py` 中是否包含策略路由

### 问题3：页面无法访问（404）
**原因**：前端路由未配置或组件路径错误

**检查**：
1. 确认 `frontend/src/router/index.ts` 中已添加回测路由
2. 确认 `frontend/src/views/Backtest/StrategyList.vue` 文件存在
3. 重启前端开发服务器

### 问题4：登录后无法访问页面
**原因**：权限配置问题

**检查**：
1. 确认用户已登录
2. 检查路由配置中的 `requiresAuth: true`
3. 检查认证状态是否正常

### 问题5：策略详情对话框参数表格为空
**原因**：API返回数据格式不匹配

**检查**：
1. 打开浏览器开发者工具 → Network
2. 查看API响应数据
3. 确认 `parameters` 字段存在且格式正确

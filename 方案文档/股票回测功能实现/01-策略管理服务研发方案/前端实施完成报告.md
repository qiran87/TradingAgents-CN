## 🔌 API集成

### 后端API接口
| 前端方法 | 后端接口 | 说明 |
|---------|---------|------|
| `getStrategies()` | `GET /api/backtest/strategies` | 获取策略列表 |
| `getStrategyDetail()` | `GET /api/backtest/strategies/{id}` | 获取策略详情 |
| `getCategories()` | `GET /api/backtest/strategies/categories` | 获取策略分类 |
| `validateParams()` | `POST /api/backtest/strategies/{id}/validate-params` | 校验参数 |

### 数据流
```
用户操作 → Store Actions → API调用 → 后端处理 → 返回数据 → 更新状态 → UI渲染
```

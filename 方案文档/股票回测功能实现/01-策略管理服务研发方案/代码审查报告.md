**改进6: 索引创建可能失败** (第245-248行)

**当前代码**:
```python
# 创建索引
await db.strategies.create_index([("category", 1), ("usage_count", -1)])
await db.strategies.create_index([("name", "text"), ("description", "text")])
await db.strategies.create_index("strategy_id", unique=True)
await db.strategy_categories.create_index("category_id", unique=True)
```

**问题**:
- 如果索引已存在会抛出异常
- 没有处理重复索引的情况
- MongoDB的`create_index`默认会忽略重复，但最好显式处理

**建议修复**:
```python
# 创建索引（忽略已存在的）
try:
    await db.strategies.create_index([("category", 1), ("usage_count", -1)], background=True)
    await db.strategies.create_index([("name", "text"), ("description", "text")], background=True)
    await db.strategies.create_index("strategy_id", unique=True, background=True)
    await db.strategy_categories.create_index("category_id", unique=True, background=True)
    logger.info("✅ 策略索引创建完成")
except Exception as e:
    logger.warning(f"⚠️  索引创建失败（可能已存在）: {e}")
    # 继续执行，不阻塞
```

**优先级**: 🟢 低 - 容错性改进

**改进8: 菜单项应该动态生成，而非硬编码**

**当前代码**:
```vue
<!-- 硬编码的菜单 -->
<el-menu-item index="/dashboard">...</el-menu-item>
<el-menu-item index="/learning">...</el-menu-item>
<!-- ... 所有菜单都是硬编码 -->
<el-sub-menu index="/backtest">
  <el-menu-item index="/backtest/strategies">策略管理</el-menu-item>
</el-sub-menu>
```

**问题**:
- 违反DRY原则
- 路由和菜单需要手动同步
- 添加新路由需要修改多处
- 容易出现不一致

**建议修复**:
```typescript
// 1. 从路由配置生成菜单
const menuRoutes = computed(() => {
  return router.getRoutes().filter(route =>
    route.meta?.title && !route.meta?.hideInMenu
  )
})

// 2. 递归渲染菜单组件
const renderMenuItems = (routes: RouteRecordRaw[]) => {
  return routes.map(route => {
    if (route.children) {
      return h(ElSubMenu, { index: route.path }, {
        title: () => [
          h(ElIcon, { icon: route.meta.icon }),
          h('span', route.meta.title)
        ],
        default: () => renderMenuItems(route.children)
      })
    } else {
      return h(ElMenuItem, { index: route.path }, {
        title: () => [
          h(ElIcon, { icon: route.meta.icon }),
          h('span', route.meta.title)
        ]
      })
    }
  })
}
```

**优先级**: 🟡 中 - 架构改进，但需要较大重构

const visibleMenuItems = computed(() => {

      return false

  })

# 如何在 Swagger 文档中查看策略接口

## 📋 问题说明

如果您在 http://localhost:8000/docs 中看不到 `backtest-strategies` 接口，通常是因为：

**策略接口需要认证才能访问，未登录时 Swagger 可能隐藏这些接口。**

## ✅ 解决步骤

### 第一步：访问 Swagger 文档

在浏览器打开：http://localhost:8000/docs

### 第二步：登录认证

1. 找到页面右上角的 🔒 **"Authorize"** 按钮（或🔓锁形图标）
2. 点击按钮，弹出登录对话框
3. 输入登录信息：
   ```
   用户名: admin
   密码: admin123
   ```
4. 点击 **"Authorize"** 或 **"登录"**
5. 点击 **"Close"** 关闭对话框

### 第三步：查看策略接口

登录后，在页面中找到 **"backtest-strategies"** 标签组，展开即可看到 4 个策略接口：

1. **GET /api/backtest/strategies** - 获取策略列表
   - 支持分类过滤、关键词搜索、排序、分页

2. **GET /api/backtest/strategies/{strategy_id}** - 获取策略详情
   - 返回策略完整信息和所有参数定义

3. **GET /api/backtest/strategies/categories** - 获取策略分类
   - 返回所有分类及每个分类的策略数量

4. **POST /api/backtest/strategies/{strategy_id}/validate-params** - 校验策略参数
   - 校验参数类型、范围、必填项等

### 第四步：测试接口

点击任意接口，然后点击 **"Try it out"** 按钮进行测试：

**示例：获取策略分类**
```
请求: GET /api/backtest/strategies/categories
响应:
[
  {
    "category_id": "trend",
    "name": "趋势跟踪策略",
    "description": "基于价格趋势的策略，适合趋势明显的市场",
    "strategy_count": 2
  },
  {
    "category_id": "oscillation",
    "name": "震荡策略",
    "description": "基于价格波动的策略，适合横盘震荡市场",
    "strategy_count": 3
  }
]
```

## 🔍 验证接口是否加载

运行验证脚本：
```bash
./verify_strategies.sh
```

如果显示：
```
✅ 策略路由已加载 (4个接口)
```

说明接口已正确加载，只需在 Swagger 中登录即可看到。

## 🐛 如果仍然看不到接口

### 1. 清除浏览器缓存

- 按 `Ctrl+Shift+R` (Windows/Linux) 或 `Cmd+Shift+R` (Mac) 强制刷新
- 或打开无痕模式访问

### 2. 确认使用的是最新应用

停止旧应用并重新启动：
```bash
# 停止旧应用
lsof -ti :8000 | xargs kill -9

# 重新启动
./start.sh
```

### 3. 检查应用日志

查看应用启动日志，确认策略初始化成功：
```bash
tail -100 logs/webapi.log | grep "策略"
```

应该看到：
```
📊 策略数据已存在 (5个策略)，跳过初始化
```

### 4. 直接测试 API

使用 curl 测试（需要先登录获取 token）：
```bash
# 1. 登录获取 token
TOKEN=$(curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}' \
  | python3 -c "import sys, json; print(json.load(sys.stdin)['access_token'])")

# 2. 使用 token 访问策略接口
curl http://localhost:8000/api/backtest/strategies/categories \
  -H "Authorization: Bearer $TOKEN" \
  | python3 -m json.tool
```

## 💡 常见问题

**Q: 为什么需要登录才能看到接口？**
A: 策略接口设计为需要认证，以保护敏感信息。Swagger 默认会隐藏需要认证但未登录的接口。

**Q: 登录后还是看不到？**
A: 尝试清除浏览器缓存或使用无痕模式。

**Q: 如何确认接口已加载？**
A: 运行 `./verify_strategies.sh` 验证脚本。

**Q: 接口返回 401 错误？**
A: 说明登录已过期，需要重新登录。

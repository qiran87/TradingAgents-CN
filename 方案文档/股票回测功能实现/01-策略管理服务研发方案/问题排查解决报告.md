### 3. 根本原因分析 🎯

**核心问题**: 策略接口需要认证才能访问，但用户未在 Swagger 中登录。

**技术细节**:
```python
# app/routers/strategies.py
@router.get("", response_model=StrategyListResponse)

    ...

```

**表现**:
- 接口已加载到 OpenAPI schema
- 返回 401 Unauthorized（未认证）
- Swagger 可能隐藏需要认证但未登录的接口

## ✅ 解决方案

### 方案1: 在 Swagger 中登录（推荐）

1. 访问 http://localhost:8000/docs
2. 点击右上角 🔒 **"Authorize"** 按钮
3. 输入登录信息：
   ```
   用户名: admin
   密码: admin123
   ```
4. 点击 **"Authorize"** 确认
5. 关闭对话框，刷新页面

**结果**: 登录后，`backtest-strategies` 标签组会出现，显示所有策略接口。

### 方案2: 使用验证脚本

运行验证脚本确认接口已加载：
```bash
./verify_strategies.sh
```

预期输出：
```
✅ 策略路由已加载 (4个接口)
  GET    /api/backtest/strategies
  GET    /api/backtest/strategies/categories
  GET    /api/backtest/strategies/{strategy_id}
  POST   /api/backtest/strategies/{strategy_id}/validate-params
```

### 方案3: 直接测试 API

使用 curl 测试（需要登录获取 token）：
```bash
# 1. 登录
TOKEN=$(curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}' \
  | python3 -c "import sys, json; print(json.load(sys.stdin)['access_token'])")

# 2. 访问策略接口
curl http://localhost:8000/api/backtest/strategies/categories \
  -H "Authorization: Bearer $TOKEN"
```

## ⚠️ 常见问题

### 问题1: 权限不足

**错误提示**: `Permission denied`

**解决方法**:
```bash
chmod +x tests/test_backtest_engine.sh
```

### 问题2: 后端服务未启动

**错误提示**: `后端服务未启动`

**解决方法**:
```bash
# 启动后端服务
./venv/bin/python3 -m app &

# 等待几秒后重新执行测试
sleep 5
./tests/test_backtest_engine.sh
```

### 问题3: jq未安装

**错误提示**: `jq: command not found`

**解决方法**:
```bash
# macOS
brew install jq

# Ubuntu/Debian
sudo apt-get install jq

# CentOS/RHEL
sudo yum install jq
```

### 问题4: 端口被占用

**错误提示**: `Connection refused`

**解决方法**:
```bash
# 检查8000端口占用
lsof -i :8000

# 终止占用进程
kill -9 <PID>

# 重启后端服务
./venv/bin/python3 -m app &
```

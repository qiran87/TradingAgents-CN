### 测试6: 交易费用计算验证

**测试目的**: 验证 A 股交易费用计算是否正确

**测试步骤**:

在 Python 中执行：

```python
from app.services.backtest_engine_service import TradingCostCalculator

# 测试买入费用：10万元
buy_cost = TradingCostCalculator.calculate_buy_cost(100000)
print("买入10万元费用:")
print(f"  佣金: {buy_cost['commission']}元 (预期: 25元，最低5元)")
print(f"  过户费: {buy_cost['transfer_fee']}元 (预期: 2元)")
print(f"  印花税: {buy_cost['stamp_duty']}元 (预期: 0元)")
print(f"  总费用: {buy_cost['total_cost']}元 (预期: 27元)")

# 测试卖出费用：10万元
sell_cost = TradingCostCalculator.calculate_sell_cost(100000)
print("\n卖出10万元费用:")
print(f"  佣金: {sell_cost['commission']}元 (预期: 25元)")
print(f"  过户费: {sell_cost['transfer_fee']}元 (预期: 2元)")
print(f"  印花税: {sell_cost['stamp_duty']}元 (预期: 100元)")
print(f"  总费用: {sell_cost['total_cost']}元 (预期: 127元)")

# 测试最低佣金：1000元
buy_cost_small = TradingCostCalculator.calculate_buy_cost(1000)
print("\n买入1000元费用:")
print(f"  佣金: {buy_cost_small['commission']}元 (预期: 5元，最低5元)")
print(f"  总费用: {buy_cost_small['total_cost']}元 (预期: 5.2元)")
```

**预期结果**:
```
买入10万元费用:
  佣金: 25.0元
  过户费: 2.0元
  印花税: 0.0元
  总费用: 27.0元

卖出10万元费用:
  佣金: 25.0元
  过户费: 2.0元
  印花税: 100.0元
  总费用: 127.0元

买入1000元费用:
  佣金: 5.0元
  总费用: 5.2元
```

**验证点**:
- ✅ 佣金 = max(金额 × 0.00025, 5)
- ✅ 过户费 = 金额 × 0.00002
- ✅ 印花税 = 金额 × 0.001（仅卖出）
- ✅ 买入无印花税

### 测试7: T+1 交易规则验证

**测试目的**: 验证 T+1 交易规则是否正确实现

**测试步骤**:

在 Python 中执行：

```python
from app.services.backtest_engine_service import BacktestState

# 创建回测状态
state = BacktestState(
    backtest_id="test_t1",
    initial_capital=100000,
    quotes=[],
    trading_days=[]
)

# 模拟买入100股
state.add_position(100, 10.0, "2024-01-02")
print(f"持仓股数: {state.position}")  # 应该是100
print(f"持仓批次数: {len(state.position_lots)}")  # 应该是1

# 测试T+1规则：买入当天不能卖出
can_sell_same_day = state.can_sell(100, "2024-01-02")
print(f"\n买入当天(2024-01-02)能否卖出100股: {can_sell_same_day}")  # 应该是False

# 测试T+1规则：第二天可以卖出
can_sell_next_day = state.can_sell(100, "2024-01-03")
print(f"第二天(2024-01-03)能否卖出100股: {can_sell_next_day}")  # 应该是True

# 测试部分卖出
cost_basis = state.sell_position(50)
print(f"\n卖出50股的成本: {cost_basis}元")  # 应该是500.0元
print(f"剩余持仓: {state.position}股")  # 应该是50股

# 验证剩余持仓批次
print(f"剩余持仓批次数: {len(state.position_lots)}")  # 应该是1
print(f"剩余批次股数: {state.position_lots[0]['shares']}")  # 应该是50
```

**预期结果**:
```
持仓股数: 100
持仓批次数: 1

买入当天(2024-01-02)能否卖出100股: False
第二天(2024-01-03)能否卖出100股: True

卖出50股的成本: 500.0元
剩余持仓: 50股
剩余持仓批次数: 1
剩余批次股数: 50
```

**验证点**:
- ✅ 买入当天不能卖出（T+1规则）
- ✅ 第二天可以卖出
- ✅ 部分卖出后剩余持仓正确
- ✅ 持仓批次正确管理

## 🐛 常见问题排查

### 问题1: 后端服务无法启动

**症状**: 执行 `./venv/bin/python3 -m app` 报错

**可能原因**:
- MongoDB 未启动
- Redis 未启动
- 端口 8000 被占用
- 依赖包缺失

**解决方案**:
```bash
# 检查 MongoDB
```

### 问题2: API 返回 404

**症状**: 调用 `/api/backtest/start` 返回 404

**可能原因**:
- 路由未正确注册
- 后端服务未重启
- 路径拼写错误

**解决方案**:
```bash
# 检查 main.py 中的路由注册
grep "backtest_engine_router" app/main.py

# 重启后端服务
lsof -ti:8000 | xargs kill -9
./venv/bin/python3 -m app &

# 验证路由
curl http://localhost:8000/docs | grep backtest
```

## 三、技术实现要点

### 3.1 Excel生成技术

**使用库**: openpyxl 3.1.5

**关键特性**:
1. **多工作簿支持**
   ```python
   wb = Workbook()
   wb.remove(wb.active)  # 删除默认工作表
   wb.create_sheet("回测摘要")
   wb.create_sheet("详细指标")
   wb.create_sheet("交易明细")
   wb.create_sheet("资金曲线")
   ```

2. **样式应用**
   ```python
   from openpyxl.styles import Font, Alignment, PatternFill, Border

   cell.font = Font(size=16, bold=True)
   cell.fill = PatternFill(start_color="4472C4", fill_type="solid")
   cell.alignment = Alignment(horizontal='center')
   cell.border = Border(...)
   ```

3. **内存操作**
   ```python
   output = io.BytesIO()
   wb.save(output)
   output.seek(0)
   excel_bytes = output.read()
   ```

### 3.2 API设计原则

**RESTful规范**:
- 使用HTTP GET(下载操作)
- 正确的Content-Type:`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`
- Content-Disposition头:`attachment; filename="..."`
- 自定义响应头:`X-File-Name`, `X-Backtest-ID`

**错误处理**:
- 404:回测结果不存在
- 500:服务器内部错误
- 统一的错误消息格式

### 3.3 前端技术要点

**Blob下载**:
```typescript
const blob = new Blob([response.data], { type: 'application/vnd...' })
const url = window.URL.createObjectURL(blob)
const link = document.createElement('a')
link.href = url
link.download = filename
link.click()
URL.revokeObjectURL(url)  // 清理内存
```

**ECharts图表导出**:
```typescript
const url = chart.getDataURL({
  type: 'png',
  pixelRatio: 2,  // 2倍分辨率
  backgroundColor: '#fff'
})
```

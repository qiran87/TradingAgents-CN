# 02-交易日历服务研发方案

## 一、领域服务概述

### 1.1 服务定位

**交易日历服务**是股票回测系统的基础数据服务，负责管理A股交易日历数据。该服务提供交易日查询、交易日判断、节假日判断等功能，是回测参数校验和回测执行的基础支撑。

### 1.2 业务边界

**本服务负责**：
- 交易日历数据管理（导入、存储、更新）
- 交易日列表查询（支持日期范围查询）
- 交易日判断（判断指定日期是否为交易日）
- 节假日判断（判断指定日期是否为节假日）
- 前后交易日查询（查找指定日期的前一个/后一个交易日）
- 交易日统计信息（年度交易日数量等）
- 交易日历数据的定期同步（通过定时任务）

**本服务不负责**：
- 交易日历数据的爬取（数据由外部数据源提供，如Tushare）
- 回测执行逻辑（由回测执行引擎服务负责）
- 股票数据管理（由股票数据服务负责）

**定时任务配置**：
- **更新频率**：每周一次（建议每周日凌晨执行）
- **数据源**：Tushare交易日历API
- **同步范围**：同步当年及次年交易日历数据

### 1.3 核心能力

1. **交易日历数据管理**
   - 交易日历数据导入（从CSV/Excel文件）
   - 交易日历数据更新（年度更新）
   - 交易日历数据验证（数据完整性检查）

2. **交易日查询**
   - 获取指定日期范围内的所有交易日
   - 获取指定年份的所有交易日
   - 获取交易日统计信息

3. **交易日判断**
   - 判断指定日期是否为交易日
   - 判断指定日期是否为节假日
   - 判断指定日期是否为周末

4. **前后交易日查询**
   - 获取指定日期的前一个交易日
   - 获取指定日期的后一个交易日
   - 支持连续查询（如前N个交易日）

5. **交易日缓存**
   - Redis缓存常用查询结果
   - 提升查询性能

### 1.4 依赖关系

**被依赖方**：
- 回测执行引擎服务（生成交易日序列、校验回测日期范围）
- 股票数据服务（数据可用性校验）
- 前端日期选择组件（禁用非交易日）

**依赖方**：
- 无（本服务是基础服务，不依赖其他业务服务）

**外部依赖**：
- MongoDB数据库（存储交易日历数据）
- Redis缓存（缓存查询结果，提升性能）
- 外部数据源（交易日历数据文件）

### 2.3 状态管理

#### Pinia Store：tradingCalendarStore.ts

```typescript
import { defineStore } from 'pinia'
import { ref } from 'vue'
import axios from 'axios'

export const useTradingCalendarStore = defineStore('tradingCalendar', () => {
  // 状态
  const tradingDaysCache = ref<Map<string, boolean>>(new Map())  // 日期 -> 是否交易日
  const tradingDaysListCache = ref<Map<string, string[]>>(new Map())  // 年份 -> 交易日列表

  // Actions
  async function isTradingDay(date: string): Promise<boolean> {
    // 检查缓存
    if (tradingDaysCache.value.has(date)) {
      return tradingDaysCache.value.get(date)!
    }

    try {
      const response = await axios.get(`/api/backtest/trading-days/${date}`)
      const isTrading = response.data.is_trading_day

      // 更新缓存
      tradingDaysCache.value.set(date, isTrading)

      return isTrading
    } catch (error) {
      console.error('判断交易日失败:', error)
      throw error
    }
  }

  async function getTradingDaysInRange(
    startDate: string,
    endDate: string
  ): Promise<string[]> {
    const cacheKey = `${startDate}_${endDate}`

    try {
      const response = await axios.get('/api/backtest/trading-days', {
        params: {
          start_date: startDate,
          end_date: endDate
        }
      })

      return response.data.trading_days
    } catch (error) {
      console.error('获取交易日列表失败:', error)
      throw error
    }
  }

  async function getPreviousTradingDay(date: string): Promise<string> {
    try {
      const response = await axios.get(`/api/backtest/trading-days/${date}/previous`)
      return response.data.previous_trading_day
    } catch (error) {
      console.error('获取前一个交易日失败:', error)
      throw error
    }
  }

  async function getNextTradingDay(date: string): Promise<string> {
    try {
      const response = await axios.get(`/api/backtest/trading-days/${date}/next`)
      return response.data.next_trading_day
    } catch (error) {
      console.error('获取后一个交易日失败:', error)
      throw error
    }
  }

  async function getTradingCalendarInfo(
    startDate: string,
    endDate: string
  ): Promise<TradingCalendarInfo> {
    try {
      const response = await axios.get('/api/backtest/trading-days/info', {
        params: {
          start_date: startDate,
          end_date: endDate
        }
      })

      return response.data
    } catch (error) {
      console.error('获取交易日历信息失败:', error)
      throw error
    }
  }

  function clearCache() {
    tradingDaysCache.value.clear()
    tradingDaysListCache.value.clear()
  }

  return {
    // 状态
    tradingDaysCache,
    tradingDaysListCache,
    // Actions
    isTradingDay,
    getTradingDaysInRange,
    getPreviousTradingDay,
    getNextTradingDay,
    getTradingCalendarInfo,
    clearCache
  }
})
```

```vue
import { ref, watch } from 'vue'
import { useTradingCalendarStore } from '@/stores/tradingCalendar'

const tradingCalendarStore = useTradingCalendarStore()

const isTradingDay = ref<boolean>(false)

// 禁用非交易日
const disabledDate = async (date: Date) => {
  const dateStr = formatDate(date)

  return trading ? 'trading-day' : 'non-trading-day'
}

// 监听日期变化
watch(selectedDate, async (newDate) => {
  if (newDate) {
    isTradingDay.value = await tradingCalendarStore.isTradingDay(newDate)
  }
})

// 选择最近的交易日
async function selectNearestTradingDay() {
  if (!selectedDate.value) return

  try {
    // 先尝试前一个交易日
    const prevTradingDay = await tradingCalendarStore.getPreviousTradingDay(selectedDate.value)
    selectedDate.value = prevTradingDay
  } catch (error) {
    // 如果前一个交易日不存在，尝试后一个交易日
    const nextTradingDay = await tradingCalendarStore.getNextTradingDay(selectedDate.value)
    selectedDate.value = nextTradingDay
  }
}

function formatDate(date: Date): string {
  const year = date.getFullYear()
  const month = String(date.getMonth() + 1).padStart(2, '0')
  const day = String(date.getDate()).padStart(2, '0')
  return `${year}-${month}-${day}`
}
```

```python
from motor.motor_asyncio import AsyncIOMotorDatabase
from typing import List, Optional, Tuple
from datetime import datetime, timedelta
import redis.asyncio as redis

class TradingCalendarService:
    """交易日历服务"""

    def __init__(self, db: AsyncIOMotorDatabase, redis_client: redis.Redis):
        self.db = db
        self.collection = db.trading_calendar
        self.redis = redis_client

    async def is_trading_day(self, date: str) -> bool:
        """
        判断指定日期是否为交易日

        Args:
            date: 日期 YYYY-MM-DD

        Returns:
            是否为交易日
        """
        # 先查Redis缓存
        cache_key = f"trading_day:{date}"
        cached = await self.redis.get(cache_key)
        if cached is not None:
            return cached == b"true"

        # 查询数据库
        trading_day = await self.collection.find_one({"date": date})

        is_trading = False
        if trading_day:
            is_trading = trading_day.get("is_trading_day", False)

        # 写入Redis缓存（24小时）
        await self.redis.setex(cache_key, 86400, b"true" if is_trading else b"false")

        return is_trading

    async def get_trading_days(
        self,
        start_date: str,
        end_date: str
    ) -> List[str]:
        """
        获取交易日列表

        Args:
            start_date: 起始日期 YYYY-MM-DD
            end_date: 结束日期 YYYY-MM-DD

        Returns:
            交易日列表
        """
        # 先查Redis缓存
        cache_key = f"trading_days:{start_date}:{end_date}"
        cached = await self.redis.get(cache_key)
        if cached:
            import json
            return json.loads(cached)

        # 查询数据库
        cursor = self.collection.find({
            "date": {"$gte": start_date, "$lte": end_date},
            "is_trading_day": True
        }).sort("date", 1)

        trading_days = await cursor.to_list(length=1000)
        trading_day_list = [td["date"] for td in trading_days]

        # 写入Redis缓存（1小时）
        import json
        await self.redis.setex(
            cache_key,
            3600,
            json.dumps(trading_day_list)
        )

        return trading_day_list

    async def get_previous_trading_day(self, date: str) -> Optional[str]:
        """
        获取前一个交易日

        Args:
            date: 日期 YYYY-MM-DD

        Returns:
            前一个交易日，如果不存在返回None
        """
        for i in range(1, 31):
            prev_date = datetime.strptime(date, "%Y-%m-%d") - timedelta(days=i)
            prev_date_str = prev_date.strftime("%Y-%m-%d")

            if await self.is_trading_day(prev_date_str):
                return prev_date_str

        return None

    async def get_next_trading_day(self, date: str) -> Optional[str]:
        """
        获取后一个交易日

        Args:
            date: 日期 YYYY-MM-DD

        Returns:
            后一个交易日，如果不存在返回None
        """
        for i in range(1, 31):
            next_date = datetime.strptime(date, "%Y-%m-%d") + timedelta(days=i)
            next_date_str = next_date.strftime("%Y-%m-%d")

            if await self.is_trading_day(next_date_str):
                return next_date_str

        return None

    async def get_trading_days_by_year(self, year: int) -> List[str]:
        """
        获取指定年份的所有交易日

        Args:
            year: 年份

        Returns:
            交易日列表
        """
        # 先查Redis缓存
        cache_key = f"trading_days:{year}"
        cached = await self.redis.get(cache_key)
        if cached:
            import json
            return json.loads(cached)

        # 查询数据库
        cursor = self.collection.find({
            "year": year,
            "is_trading_day": True
        }).sort("date", 1)

        trading_days = await cursor.to_list(length=400)
        trading_day_list = [td["date"] for td in trading_days]

        # 写入Redis缓存（24小时）
        import json
        await self.redis.setex(
            cache_key,
            86400,
            json.dumps(trading_day_list)
        )

        return trading_day_list

    async def import_trading_calendar_from_csv(self, csv_file_path: str) -> int:
        """
        从CSV文件导入交易日历数据

        CSV格式：
        date,is_trading_day,is_holiday,holiday_name
        2023-01-01,false,true,"元旦节"
        2023-01-02,false,true,"元旦节"
        2023-01-03,true,false,""

        Args:
            csv_file_path: CSV文件路径

        Returns:
            导入的记录数
        """
        import csv
        from datetime import datetime

        documents = []
        count = 0

        with open(csv_file_path, 'r', encoding='utf-8') as f:
            reader = csv.DictReader(f)

            for row in reader:
                date = datetime.strptime(row['date'], "%Y-%m-%d")

                doc = {
                    "date": row['date'],
                    "year": date.year,
                    "month": date.month,
                    "day": date.day,
                    "weekday": date.weekday() + 1,  # 周一为1
                    "is_trading_day": row['is_trading_day'].lower() == 'true',
                    "is_holiday": row['is_holiday'].lower() == 'true',
                    "holiday_name": row.get('holiday_name') or None,
                    "is_weekend": date.weekday() >= 5,  # 周六、周日
                    "created_at": datetime.utcnow(),
                    "updated_at": datetime.utcnow()
                }

                documents.append(doc)
                count += 1

                # 批量插入（每1000条）
                if len(documents) >= 1000:
                    await self.collection.insert_many(documents)
                    documents = []

        # 插入剩余的记录
        if documents:
            await self.collection.insert_many(documents)

        return count
```

```python
async def clear_cache_for_year(self, year: int):
    """清除指定年份的所有缓存"""
    # 清除年度交易日列表缓存
    await self.redis.delete(f"trading_days:{year}")

    # 清除该年份所有日期的缓存
    # 使用SCAN命令避免阻塞
    cursor = 0
    pattern = "trading_day:"

    while True:
        cursor, keys = await self.redis.scan(
            cursor=cursor,
            match=f"{pattern}{year}-*",
            count=100
        )

        if keys:
            await self.redis.delete(*keys)

        if cursor == 0:
            break
```

#### 3.5.3 交易日历数据验证

**数据完整性检查**:
```python
async def validate_trading_calendar_data(self, year: int) -> dict:
    """
    验证交易日历数据的完整性

    Args:
        year: 年份

    Returns:
        验证结果
    """
    issues = []

    # 1. 检查是否有重复日期
    pipeline = [
        {"$match": {"year": year}},
        {"$group": {"_id": "$date", "count": {"$sum": 1}}},
        {"$match": {"count": {"$gt": 1}}}
    ]

    duplicates = await self.collection.aggregate(pipeline).to_list(length=100)
    if duplicates:
        issues.append(f"发现 {len(duplicates)} 个重复日期")

    # 2. 检查缺失日期
    from datetime import datetime, date

    start_date = date(year, 1, 1)
    end_date = date(year, 12, 31)

    existing_dates = set()
    cursor = self.collection.find(
        {"year": year},
        projection={"date": 1}
    )

    async for doc in cursor:
        existing_dates.add(doc["date"])

    missing_dates = []
    current_date = start_date

    while current_date <= end_date:
        date_str = current_date.strftime("%Y-%m-%d")
        if date_str not in existing_dates:
            missing_dates.append(date_str)
        current_date += timedelta(days=1)

    if missing_dates:
        issues.append(f"缺失 {len(missing_dates)} 个日期")

    # 3. 检查逻辑一致性
    # 周末应该是非交易日（除非调休）
    cursor = self.collection.find({
        "year": year,
        "is_weekend": True,
        "is_trading_day": True
    })

    weekend_trading_days = await cursor.to_list(length=100)
    if weekend_trading_days:
        issues.append(f"发现 {len(weekend_trading_days)} 个周末交易日（可能是调休）")

    # 4. 统计交易日数量
    trading_days_count = await self.collection.count_documents({
        "year": year,
        "is_trading_day": True
    })

    # A股通常每年约244个交易日
    if trading_days_count < 240 or trading_days_count > 250:
        issues.append(f"交易日数量异常：{trading_days_count}（正常范围：240-250）")

    return {
        "year": year,
        "valid": len(issues) == 0,
        "issues": issues,
        "trading_days_count": trading_days_count
    }
```

### 4.2 数据格式约定

#### 4.2.1 日期格式约定

**格式**: `YYYY-MM-DD`

**示例**: `2023-01-03`

**前端处理**:
```typescript
function formatDate(date: Date): string {
  const year = date.getFullYear()
  const month = String(date.getMonth() + 1).padStart(2, '0')
  const day = String(date.getDate()).padStart(2, '0')
  return `${year}-${month}-${day}`
}

function parseDate(dateStr: string): Date {
  const [year, month, day] = dateStr.split('-').map(Number)
  return new Date(year, month - 1, day)
}
```

#### 4.2.2 星期格式约定

**后端返回**: 数字（1-7）
- 1：周一
- 2：周二
- ...
- 7：周日

**前端显示**:
```typescript
function formatWeekday(weekday: number): string {
  const weekdays = ['周一', '周二', '周三', '周四', '周五', '周六', '周日']
  return weekdays[weekday - 1] || ''
}
```

您**现在**就可以通过API使用所有功能：

```bash

# 3. 软删除（移至回收站）
DELETE /api/backtest/history/{record_id}

# 4. 永久删除
DELETE /api/backtest/history/{record_id}?permanent=true

# 5. 批量删除
POST /api/backtest/history/batch-delete
Body: {"record_ids": ["id1", "id2"], "permanent": false}

# 6. 恢复记录
POST /api/backtest/history/{record_id}/restore

# 7. 导出记录
GET /api/backtest/history/{record_id}/export?format=json

# 8. 对比记录
POST /api/backtest/history/compare
Body: {"record_ids": ["id1", "id2", "id3"]}
```

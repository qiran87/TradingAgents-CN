#### 1.0.8 页面交互流程

**完整流程**:
1. **页面加载**:
   - 检查 localStorage `backtest_guide_shown`
   - 无记录 → 500ms后显示新手指引弹窗
   - 加载常用参数列表

2. **设置参数**:
   - 用户填写日期、资金、购买量、股票代码
   - 点击"参数确认" → 表单验证 → 成功提示

3. **选择策略**:
   - 用户筛选/搜索策略
   - 点击单选按钮选择策略
   - 配置策略参数 (如有)
   - 点击"策略确认" → 成功提示

4. **触发回测**:
   - 点击"开始回测" → 检查 `backtest_guide_shown`
   - 无记录 → 显示新手指引弹窗
   - 有记录 → 显示参数确认弹窗
   - 确认 → 调用 API → 显示进度条

5. **回测进行中**:
   - WebSocket 实时推送进度
   - 更新进度条、当前日期、持仓数据
   - 用户可点击"中断回测"

6. **回测完成**:
   - 进度条变绿 (100%)
   - 显示回测结果展示区
   - 用户可查看明细、导出、重新回测

**现有组件**: ✅ 已完整实现,无需调整

## 🔗 跨页面调用流程设计

### 流程1: 快速回测流程

**用户目标**: 从策略列表快速启动回测

**流程步骤**:
1. 用户进入 `/backtest/strategies` 浏览策略
2. 点击某个策略的"使用此策略"按钮
3. 系统跳转到 `/backtest/control`
4. 自动填充该策略到"策略选择"区域
5. 自动展开策略参数配置表单
6. 用户继续设置日期、资金等参数
7. 点击"开始回测"按钮

**技术实现**:
```typescript
// 策略列表页面
const handleUseStrategy = (strategy: Strategy) => {
  // 保存选中的策略到全局状态
  backtestStore.setSelectedStrategy(strategy)
  // 跳转到回测控制页面
  router.push('/backtest/control')
}

// 回测控制页面
onMounted(() => {
  // 检查是否有预选策略
  if (backtestStore.selectedStrategy) {
    form.strategy = backtestStore.selectedStrategy.id
    // 自动展开参数配置
    showParamsConfig.value = true
  }
})
```

### 流程2: 从历史记录快速重新回测

**用户目标**: 使用历史记录的参数快速创建新回测

**流程步骤**:
1. 用户进入 `/backtest/history` 查看历史记录
2. 点击某条记录的"重新回测"按钮
3. 系统跳转到 `/backtest/control`
4. 自动填充所有参数(股票、日期、资金、策略及参数)
5. 用户可以修改参数或直接开始回测

**技术实现**:
```typescript
// 历史记录页面
const handleRerun = (record: HistoryRecord) => {
  // 保存记录的参数到全局状态
  backtestStore.setRerunParams(record.parameters)
  // 跳转到回测控制页面
  router.push('/backtest/control?mode=rerun')
}

// 回测控制页面
onMounted(() => {
  if (route.query.mode === 'rerun' && backtestStore.rerunParams) {
    // 填充所有参数
    Object.assign(form, backtestStore.rerunParams)
    // 提示用户参数已恢复
    ElMessage.success('已恢复历史参数,可直接开始回测')
  }
})
```

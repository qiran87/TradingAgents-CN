# 03-股票数据服务研发方案

## 一、领域服务概述

### 1.1 服务定位

**股票数据服务**是股票回测系统的数据基础服务，负责股票行情数据的查询和管理。该服务提供股票基础信息查询、历史行情数据查询、数据可用性校验等功能，是回测执行的数据来源。

### 1.2 业务边界

**本服务负责**：
- 股票基础信息查询（股票名称、市场、行业等）
- 历史行情数据查询（日级别OHLCV数据）
- 数据可用性校验（检查指定日期范围是否有完整数据）
- 数据完整性检查（检查是否有缺失交易日）
- 数据缓存（Redis缓存常用查询）

**本服务不负责**：
- 股票数据的爬取和更新（数据由外部数据源提供，通过现有的数据更新服务维护）
- 股票数据的存储（数据从MongoDB读取）
- 实时行情推送（只提供历史数据）
- 分钟级别数据（只提供日级别数据）

**重要说明**：
- 本服务**复用现有的** `app/services/stock_data_service.py` 和 `app/routers/stock_data.py`
- 所有数据从**MongoDB数据库**读取，不直接调用外部API（避免产生费用）
- 数据来源包括：Tushare、AKShare、BaoStock等多数据源
- 如果回测需要的新增功能在现有服务中不存在，则扩展现有服务而不是新建

### 1.3 核心能力

1. **股票基础信息查询**
   - 根据股票代码查询股票名称、市场、行业
   - 批量查询股票信息
   - 股票搜索（按名称或代码）

2. **历史行情数据查询**
   - 查询指定日期范围的历史行情
   - 查询指定日期的单日行情
   - 批量查询多只股票的行情
   - 支持分页查询

3. **数据可用性校验**
   - 检查指定日期范围是否有完整数据
   - 检查是否有缺失交易日
   - 计算数据覆盖率

4. **数据缓存**
   - Redis缓存常用股票信息
   - Redis缓存常用行情数据
   - 提升查询性能

5. **数据统计**
   - 统计数据时间范围
   - 统计数据完整性
   - 统计数据更新时间

### 1.4 依赖关系

**被依赖方**：
- 回测执行引擎服务（获取行情数据）
- 前端回测页面（展示股票信息）

**依赖方**：
- 交易日历服务（校验交易日）

**外部依赖**：
- MongoDB数据库（存储股票数据和行情数据，多数据源）
- Redis缓存（缓存查询结果）

### 2.3 状态管理

#### Pinia Store：stockDataStore.ts

```typescript
import { defineStore } from 'pinia'
import { ref } from 'vue'
import axios from 'axios'

export const useStockDataStore = defineStore('stockData', () => {
  // 状态
  const stockInfoCache = ref<Map<string, StockInfo>>(new Map())
  const quotesCache = ref<Map<string, QuoteData[]>>(new Map())

  // Actions
  async function getStockInfo(stockCode: string): Promise<StockInfo> {
    // 检查缓存
    if (stockInfoCache.value.has(stockCode)) {
      return stockInfoCache.value.get(stockCode)!
    }

    try {
      const response = await axios.get(`/api/backtest/stock/info`, {
        params: { stock_code: stockCode }
      })

      const info = response.data

      // 更新缓存
      stockInfoCache.value.set(stockCode, info)

      return info
    } catch (error) {
      console.error('获取股票信息失败:', error)
      throw error
    }
  }

  async function getQuotes(
    stockCode: string,
    startDate: string,
    endDate: string
  ): Promise<QuoteData[]> {
    const cacheKey = `${stockCode}_${startDate}_${endDate}`

    // 检查缓存
    if (quotesCache.value.has(cacheKey)) {
      return quotesCache.value.get(cacheKey)!
    }

    try {
      const response = await axios.get(`/api/backtest/stock/quotes`, {
        params: {
          stock_code: stockCode,
          start_date: startDate,
          end_date: endDate
        }
      })

      const quotes = response.data.quotes

      // 更新缓存
      quotesCache.value.set(cacheKey, quotes)

      return quotes
    } catch (error) {
      console.error('获取行情数据失败:', error)
      throw error
    }
  }

  async function checkDataAvailability(
    stockCode: string,
    startDate: string,
    endDate: string
  ): Promise<DataAvailabilityInfo> {
    try {
      const response = await axios.get(`/api/backtest/stock/quotes/check-availability`, {
        params: {
          stock_code: stockCode,
          start_date: startDate,
          end_date: endDate
        }
      })

      return response.data
    } catch (error) {
      console.error('检查数据可用性失败:', error)
      throw error
    }
  }

  async function searchStocks(keyword: string, limit: number = 10): Promise<StockOption[]> {
    try {
      const response = await axios.get(`/api/backtest/stock/search`, {
        params: {
          keyword,
          limit
        }
      })

      return response.data.stocks
    } catch (error) {
      console.error('搜索股票失败:', error)
      throw error
    }
  }

  function clearCache() {
    stockInfoCache.value.clear()
    quotesCache.value.clear()
  }

  return {
    // 状态
    stockInfoCache,
    quotesCache,
    // Actions
    getStockInfo,
    getQuotes,
    checkDataAvailability,
    searchStocks,
    clearCache
  }
})
```

### 2.5 实现要点

#### 2.5.1 股票搜索优化

**搜索策略**：
```typescript
async function searchStocks(keyword: string): Promise<StockOption[]> {
  // 1. 如果是纯数字，优先按代码搜索
  if (/^\d+$/.test(keyword)) {
    const result = await stockDataApi.searchStocks(keyword, 10)
    return result.stocks
  }

  // 2. 如果包含字母或中文，按名称搜索
  const result = await stockDataApi.searchStocks(keyword, 10)

  // 3. 结果排序：优先显示完全匹配的
  return result.stocks.sort((a, b) => {
    const aExactMatch = a.stock_code === keyword || a.stock_name === keyword
    const bExactMatch = b.stock_code === keyword || b.stock_name === keyword

    if (aExactMatch && !bExactMatch) return -1
    if (!aExactMatch && bExactMatch) return 1
    return 0
  })
}

<script setup lang="ts">

import { useStockDataStore } from '@/stores/stockData'

const stockDataStore = useStockDataStore()

const availabilityInfo = ref<DataAvailabilityInfo | null>(null)

const availabilityType = computed(() => {
  if (!availabilityInfo.value) return 'info'

  const coverage = availabilityInfo.value.coverage
  if (coverage >= 0.95) return 'success'
  if (coverage >= 0.80) return 'warning'
  return 'error'
})

const progressColor = computed(() => {
  if (!availabilityInfo.value) return '#409eff'

  const coverage = availabilityInfo.value.coverage
  if (coverage >= 0.95) return '#67c23a'
  if (coverage >= 0.80) return '#e6a23c'
  return '#f56c6c'
})

async function checkAvailability() {
  if (!props.stockCode || !props.dateRange) return

  try {
    availabilityInfo.value = await stockDataStore.checkDataAvailability(
      props.stockCode,
      props.dateRange.start,
      props.dateRange.end

    console.error('检查数据可用性失败:', error)
  }
}

      customClass: 'missing-dates-dialog'
    }
  )
}

        market=stock_info["market"],

async def import_quotes_from_csv(
    self,
    stock_code: str,
    csv_file_path: str
) -> int:
    """
    从CSV文件导入行情数据

    CSV格式：
    date,open,high,low,close,volume,amount
    2023-01-03,12.50,12.68,12.45,12.60,125680000,1585120000

    Args:
        stock_code: 股票代码
        csv_file_path: CSV文件路径

    Returns:
        导入的记录数
    """
    import csv
    from datetime import datetime

    documents = []
    count = 0

    with open(csv_file_path, 'r', encoding='utf-8') as f:
        reader = csv.DictReader(f)

        for row in reader:
            doc = {
                "stock_code": stock_code,
                "date": row['date'],
                "open": float(row['open']),
                "high": float(row['high']),
                "low": float(row['low']),
                "close": float(row['close']),
                "volume": int(row['volume']),
                "amount": float(row['amount']),
                "created_at": datetime.utcnow(),
                "updated_at": datetime.utcnow()
            }

            documents.append(doc)
            count += 1

            # 批量插入
            if len(documents) >= 1000:
                await self.stock_quotes_collection.bulk_write([
                    {
                        "update_one": {
                            "filter": {"stock_code": doc["stock_code"], "date": doc["date"]},
                            "update": {"$set": doc},
                            "upsert": True
                        }
                    }
                    for doc in documents
                ])
                documents = []

    # 插入剩余记录
    if documents:
        await self.stock_quotes_collection.bulk_write([
            {
                "update_one": {
                    "filter": {"stock_code": doc["stock_code"], "date": doc["date"]},
                    "update": {"$set": doc},
                    "upsert": True
                }
            }
            for doc in documents
        ])

    # 清除相关缓存
    await self._clear_quotes_cache(stock_code)

    return count

async def _clear_quotes_cache(self, stock_code: str):
    """清除行情数据缓存"""
    # 使用SCAN删除所有相关缓存
    cursor = 0
    pattern = f"stock_quotes:{stock_code}:*"

    while True:
        cursor, keys = await self.redis.scan(
            cursor=cursor,
            match=pattern,
            count=100
        )

        if keys:
            await self.redis.delete(*keys)

        if cursor == 0:
            break

async def validate_data_integrity(
    self,
    stock_code: str,
    start_date: str,
    end_date: str
) -> Dict[str, Any]:

    Args:
        stock_code: 股票代码
        start_date: 起始日期
        end_date: 结束日期

    Returns:
        验证结果

    # 1. 检查缺失交易日
    availability = await self.check_data_availability(
        stock_code, start_date, end_date
    )

    if availability["missing_dates"]:
        issues.append(f"缺失 {len(availability['missing_dates'])} 个交易日")

    # 2. 检查数据异常（如价格为0或负数）
    cursor = self.stock_quotes_collection.find({
        "stock_code": stock_code,
        "date": {"$gte": start_date, "$lte": end_date},
        "$or": [
            {"open": {"$lte": 0}},
            {"high": {"$lte": 0}},
            {"low": {"$lte": 0}},
            {"close": {"$lte": 0}},
            {"volume": {"$lt": 0}}
        ]
    })

    abnormal_quotes = await cursor.to_list(length=100)
    if abnormal_quotes:
        issues.append(f"发现 {len(abnormal_quotes)} 条异常数据（价格或成交量为负数）")

    # 3. 检查价格逻辑性（最高价 >= 最低价）
    cursor = self.stock_quotes_collection.find({
        "stock_code": stock_code,
        "date": {"$gte": start_date, "$lte": end_date},
        "$expr": {"$lt": ["$high", "$low"]}
    })

    illogical_quotes = await cursor.to_list(length=100)
    if illogical_quotes:
        issues.append(f"发现 {len(illogical_quotes)} 条逻辑错误（最高价 < 最低价）")

    return {
        "stock_code": stock_code,
        "date_range": {"start_date": start_date, "end_date": end_date},
        "valid": len(issues) == 0,
        "issues": issues,
        "coverage": availability["coverage"]
    }
```

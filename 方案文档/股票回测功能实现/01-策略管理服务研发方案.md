# 01-策略管理服务研发方案

## 一、领域服务概述

### 1.1 服务定位

**策略管理服务**是股票回测系统的基础服务之一，负责管理交易策略的全生命周期。该服务提供策略的注册、查询、分类、参数定义等功能，是回测执行的前提条件。

### 1.2 业务边界

**本服务负责**：
- 策略元数据管理（策略ID、名称、描述、分类等）
- 策略参数定义（参数名称、类型、默认值、范围约束）
- 策略分类管理（趋势跟踪、均值回归、动量策略等）
- 策略查询与搜索
- 策略参数校验逻辑
- 策略代码管理与注册

**本服务不负责**：
- 策略执行逻辑（由回测执行引擎负责）
- 策略性能评估（由结果计算服务负责）

**重要说明**：
- 策略代码位于 `app/strategies/` 目录，与回测模块解耦
- 策略可被**回测**和**模拟实盘交易**等多个模块复用
- 策略代码硬编码在系统中，不提供动态加载功能

### 1.3 核心能力

1. **策略库管理**
   - 内置策略：双均线策略、布林带策略、MACD策略等
   - 自定义策略：用户创建的策略（预留接口）

2. **策略分类管理**
   - 按策略类型分类：趋势策略、震荡策略、动量策略
   - 按时间周期分类：日线策略、周线策略
   - 按复杂度分类：简单策略、复杂策略

3. **策略查询**
   - 列表查询：支持分页、排序
   - 详情查询：获取策略完整信息
   - 搜索查询：按名称/描述关键词搜索
   - 过滤查询：按分类、参数数量等条件过滤

4. **策略参数管理**
   - 参数定义：名称、类型、默认值、取值范围、描述
   - 参数校验：类型校验、范围校验、业务规则校验
   - 参数依赖：参数之间的依赖关系定义

5. **使用统计**
   - 策略使用次数统计
   - 策略创建回测次数统计

### 1.4 依赖关系

**被依赖方**：
- 回测执行引擎服务（需要获取策略定义和参数）
- 前端策略列表页面（需要展示策略信息）

**依赖方**：
- 无（本服务是基础服务，不依赖其他业务服务）

**外部依赖**：
- MongoDB数据库（存储策略元数据）

### 2.3 状态管理

#### Pinia Store：strategyStore.ts

```typescript
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'
import axios from 'axios'

export const useStrategyStore = defineStore('strategy', () => {
  // 状态
  const strategies = ref<StrategySummary[]>([])
  const categories = ref<StrategyCategory[]>([])
  const currentCategory = ref<string>('all')
  const searchKeyword = ref<string>('')
  const sortBy = ref<string>('usage_count')
  const loading = ref<boolean>(false)
  const currentStrategy = ref<StrategyDetail | null>(null)

  // 计算属性
  const filteredStrategies = computed(() => {
    let result = strategies.value

    // 分类过滤
    if (currentCategory.value !== 'all') {
      result = result.filter(s => s.category === currentCategory.value)
    }

    // 关键词搜索
    if (searchKeyword.value) {
      const keyword = searchKeyword.value.toLowerCase()
      result = result.filter(s =>
        s.name.toLowerCase().includes(keyword) ||
        s.description.toLowerCase().includes(keyword)
      )
    }

    // 排序
    result = [...result].sort((a, b) => {
      switch (sortBy.value) {
        case 'usage_count':
          return b.usage_count - a.usage_count
        case 'created_at':
          return new Date(b.created_at).getTime() - new Date(a.created_at).getTime()
        case 'name_asc':
          return a.name.localeCompare(b.name, 'zh-CN')
        case 'name_desc':
          return b.name.localeCompare(a.name, 'zh-CN')
        default:
          return 0
      }
    })

    return result
  })

  // Actions
  async function fetchStrategies() {
    loading.value = true
    try {
      const response = await axios.get('/api/backtest/strategies')
      strategies.value = response.data.strategies
    } catch (error) {
      console.error('获取策略列表失败:', error)
      throw error
    } finally {
      loading.value = false
    }
  }

  async function fetchCategories() {
    try {
      const response = await axios.get('/api/backtest/strategies/categories')
      categories.value = response.data.categories
    } catch (error) {
      console.error('获取策略分类失败:', error)
      throw error
    }
  }

  async function fetchStrategyDetail(strategyId: string) {
    try {
      const response = await axios.get(`/api/backtest/strategies/${strategyId}`)
      currentStrategy.value = response.data
      return response.data
    } catch (error) {
      console.error('获取策略详情失败:', error)
      throw error
    }
  }

  async function validateParams(strategyId: string, params: Record<string, any>) {
    try {
      const response = await axios.post(
        `/api/backtest/strategies/${strategyId}/validate-params`,
        { params }
      )
      return response.data
    } catch (error) {
      console.error('校验策略参数失败:', error)
      throw error
    }
  }

  function setCategory(category: string) {
    currentCategory.value = category
  }

  function setSearchKeyword(keyword: string) {
    searchKeyword.value = keyword
  }

  function setSortBy(sort: string) {
    sortBy.value = sort
  }

  return {
    // 状态
    strategies,
    categories,
    currentCategory,
    searchKeyword,
    sortBy,
    loading,
    currentStrategy,
    // 计算属性
    filteredStrategies,
    // Actions
    fetchStrategies,
    fetchCategories,
    fetchStrategyDetail,
    validateParams,
    setCategory,
    setSearchKeyword,
    setSortBy
  }
})
```

### 2.4 API调用

#### API接口定义：strategyApi.ts

```typescript
import axios from 'axios'

const BASE_URL = '/api/backtest/strategies'

export interface StrategySummary {
  strategy_id: string
  name: string
  description: string
  category: string
  parameter_count: number
  usage_count: number
  is_builtin: boolean
}

export interface StrategyDetail extends StrategySummary {
  long_description?: string
  parameters: StrategyParameter[]
  created_at: string
}

export interface StrategyParameter {
  name: string
  type: 'int' | 'float' | 'bool' | 'string' | 'list'
  default_value: any
  range?: {
    min?: number
    max?: number
  }
  options?: string[]
  description: string
  required: boolean
}

export interface StrategyCategory {
  category_id: string
  name: string
  description?: string
  strategy_count: number
}

export interface ValidateParamsRequest {
  params: Record<string, any>
}

export interface ValidateParamsResponse {
  valid: boolean
  errors?: Record<string, string>
}

export const strategyApi = {
  /**
   * 获取策略列表
   */
  async getStrategies(): Promise<{ strategies: StrategySummary[] }> {
    const response = await axios.get(BASE_URL)
    return response.data
  },

  /**
   * 获取策略详情
   */
  async getStrategyDetail(strategyId: string): Promise<StrategyDetail> {
    const response = await axios.get(`${BASE_URL}/${strategyId}`)
    return response.data
  },

  /**
   * 获取策略分类
   */
  async getCategories(): Promise<{ categories: StrategyCategory[] }> {
    const response = await axios.get(`${BASE_URL}/categories`)
    return response.data
  },

  /**
   * 校验策略参数
   */
  async validateParams(
    strategyId: string,
    request: ValidateParamsRequest
  ): Promise<ValidateParamsResponse> {
    const response = await axios.post(
      `${BASE_URL}/${strategyId}/validate-params`,
      request
    )
    return response.data
  }
}
```

@router.post("/{strategy_id}/validate-params", response_model=ValidateParamsResponse)
async def validate_strategy_params(
    strategy_id: str,
    request: ValidateParamsRequest,
    db: AsyncIOMotorDatabase = Depends(get_database)
):
    """
    校验策略参数

    校验参数的类型、范围、必填等规则
    """
    # 获取策略定义
    strategy = await db.strategies.find_one({"strategy_id": strategy_id})

    if not strategy:
        raise HTTPException(status_code=404, detail=f"策略 {strategy_id} 不存在")

    errors = {}
    params = request.params
    parameter_defs = {p["name"]: p for p in strategy["parameters"]}

    # 校验每个参数
    for param_def in strategy["parameters"]:
        param_name = param_def["name"]
        param_type = param_def["type"]
        required = param_def["required"]
        range_limit = param_def.get("range")
        options = param_def.get("options")

        # 检查必填参数
        if required and param_name not in params:
            errors[param_name] = f"参数 {param_name} 是必填的"
            continue

        # 如果参数不存在且非必填，跳过
        if param_name not in params:
            continue

        param_value = params[param_name]

        # 类型校验
        try:
            if param_type == "int":
                if not isinstance(param_value, int):
                    errors[param_name] = f"参数 {param_name} 应为整数"
                    continue
            elif param_type == "float":
                if not isinstance(param_value, (int, float)):
                    errors[param_name] = f"参数 {param_name} 应为数字"
                    continue
            elif param_type == "bool":
                if not isinstance(param_value, bool):
                    errors[param_name] = f"参数 {param_name} 应为布尔值"
                    continue
            elif param_type == "string":
                if not isinstance(param_value, str):
                    errors[param_name] = f"参数 {param_name} 应为字符串"
                    continue
            elif param_type == "list":
                if not isinstance(param_value, str):
                    errors[param_name] = f"参数 {param_name} 应为字符串(从选项中选择)"
                    continue
        except Exception as e:
            errors[param_name] = f"参数 {param_name} 类型校验失败: {str(e)}"
            continue

        # 范围校验
        if range_limit and param_type in ["int", "float"]:
            if "min" in range_limit and param_value < range_limit["min"]:
                errors[param_name] = f"参数 {param_name} 不能小于 {range_limit['min']}"
                continue
            if "max" in range_limit and param_value > range_limit["max"]:
                errors[param_name] = f"参数 {param_name} 不能大于 {range_limit['max']}"
                continue

        # 选项校验
        if options and param_type == "list":
            if param_value not in options:
                errors[param_name] = f"参数 {param_name} 必须是以下之一: {', '.join(options)}"
                continue

    # 返回校验结果
    return ValidateParamsResponse(
        valid=len(errors) == 0,
        errors=errors if errors else None
    )

from motor.motor_asyncio import AsyncIOMotorDatabase
from typing import List, Optional, Dict, Any
from datetime import datetime
from bson import ObjectId

class StrategyService:
    """策略管理服务"""

    def __init__(self, db: AsyncIOMotorDatabase):
        self.db = db
        self.collection = db.strategies
        self.category_collection = db.strategy_categories

    async def get_strategy_by_id(self, strategy_id: str) -> Optional[Dict[str, Any]]:
        """
        根据策略ID获取策略

        Args:
            strategy_id: 策略ID

        Returns:
            策略文档，如果不存在返回None
        """
        return await self.collection.find_one({"strategy_id": strategy_id})

    async def strategy_exists(self, strategy_id: str) -> bool:
        """
        检查策略是否存在

        Args:
            strategy_id: 策略ID

        Returns:
            是否存在
        """
        count = await self.collection.count_documents({"strategy_id": strategy_id})
        return count > 0

    async def increment_usage_count(self, strategy_id: str):
        """
        增加策略使用次数

        Args:
            strategy_id: 策略ID
        """
        await self.collection.update_one(
            {"strategy_id": strategy_id},
            {"$inc": {"usage_count": 1}}
        )

    async def get_strategy_parameters(self, strategy_id: str) -> List[Dict[str, Any]]:
        """
        获取策略参数定义

        Args:
            strategy_id: 策略ID

        Returns:
            参数定义列表
        """
        strategy = await self.get_strategy_by_id(strategy_id)
        if not strategy:
            return []
        return strategy.get("parameters", [])

    async def search_strategies(
        self,
        keyword: Optional[str] = None,
        category: Optional[str] = None,
        skip: int = 0,
        limit: int = 50
    ) -> List[Dict[str, Any]]:
        """
        搜索策略

        Args:
            keyword: 搜索关键词
            category: 分类过滤
            skip: 跳过条数
            limit: 返回条数

        Returns:
            策略列表
        """
        query = {}

        if category:
            query["category"] = category

        if keyword:
            query["$text"] = {"$search": keyword}

        cursor = self.collection.find(query).sort("usage_count", -1).skip(skip).limit(limit)
        return await cursor.to_list(length=limit)

    async def get_all_categories(self) -> List[Dict[str, Any]]:
        """
        获取所有分类

        Returns:
            分类列表
        """
        cursor = self.category_collection.find().sort("sort_order", 1)
        return await cursor.to_list(length=100)

    async def validate_parameters(
        self,
        strategy_id: str,
        params: Dict[str, Any]
    ) -> tuple[bool, Optional[Dict[str, str]]]:
        """
        校验策略参数

        Args:
            strategy_id: 策略ID
            params: 参数字典

        Returns:
            (是否有效, 错误信息字典)
        """
        strategy = await self.get_strategy_by_id(strategy_id)
        if not strategy:
            return False, {"strategy": f"策略 {strategy_id} 不存在"}

        errors = {}
        parameter_defs = {p["name"]: p for p in strategy["parameters"]}

        for param_def in strategy["parameters"]:
            param_name = param_def["name"]
            param_type = param_def["type"]
            required = param_def["required"]
            range_limit = param_def.get("range")
            options = param_def.get("options")

            # 必填检查
            if required and param_name not in params:
                errors[param_name] = f"参数 {param_name} 是必填的"
                continue

            if param_name not in params:
                continue

            param_value = params[param_name]

            # 类型检查
            if not self._validate_type(param_value, param_type):
                errors[param_name] = f"参数 {param_name} 类型错误，应为 {param_type}"
                continue

            # 范围检查
            if range_limit and not self._validate_range(param_value, range_limit):
                errors[param_name] = f"参数 {param_name} 超出范围 {range_limit}"
                continue

            # 选项检查
            if options and param_value not in options:
                errors[param_name] = f"参数 {param_name} 必须是以下之一: {options}"
                continue

        return len(errors) == 0, errors if errors else None

    def _validate_type(self, value: Any, expected_type: str) -> bool:
        """验证值类型"""
        type_map = {
            "int": int,
            "float": (int, float),
            "bool": bool,
            "string": str,
            "list": str
        }
        expected = type_map.get(expected_type)
        return isinstance(value, expected) if expected else False

    def _validate_range(self, value: Any, range_limit: Dict[str, Any]) -> bool:
        """验证值范围"""
        if not isinstance(value, (int, float)):
            return False

        if "min" in range_limit and value < range_limit["min"]:
            return False

        if "max" in range_limit and value > range_limit["max"]:
            return False

        return True

from abc import ABC, abstractmethod
from typing import Dict, Any, List
from datetime import datetime

class BaseStrategy(ABC):
    """策略基类"""

    def __init__(self, params: Dict[str, Any]):
        """
        初始化策略

        Args:
            params: 策略参数
        """
        self.params = params
        self.validate_params()

    @abstractmethod
    def get_parameters_definition(self) -> List[Dict[str, Any]]:
        """
        获取参数定义

        Returns:
            参数定义列表
        """
        pass

    def validate_params(self):
        """校验参数"""
        param_defs = self.get_parameters_definition()
        param_def_dict = {p["name"]: p for p in param_defs}

        for param_def in param_defs:
            param_name = param_def["name"]
            required = param_def.get("required", True)

            if required and param_name not in self.params:
                raise ValueError(f"参数 {param_name} 是必填的")

    @abstractmethod
    def on_bar(
        self,
        bar_id: str,
        timestamp: datetime,
        current_price: float,
        position: int,
        cash: float
    ) -> Dict[str, Any]:
        """

            {
                "action": "buy" | "sell" | "hold",
                "amount": int,  # 交易股数
                "reason": str   # 原因说明
            }
        """
        pass

    @abstractmethod
    def get_strategy_name(self) -> str:
        """获取策略名称"""

#### 3.5.2 参数校验增强

**业务规则校验示例**：
```python
async def validate_parameters_with_business_rules(
    self,
    strategy_id: str,
    params: Dict[str, Any]
) -> tuple[bool, Optional[Dict[str, str]]]:
    """
    校验策略参数（包含业务规则）

    Args:
        strategy_id: 策略ID
        params: 参数字典

    Returns:
        (是否有效, 错误信息字典)
    """
    # 基础校验
    is_valid, errors = await self.validate_parameters(strategy_id, params)
    if not is_valid:
        return False, errors

    # 业务规则校验
    if strategy_id == "dual_ma":
        # 双均线策略：短期窗口必须小于长期窗口
        if params["short_window"] >= params["long_window"]:
            errors = errors or {}
            errors["long_window"] = "长期窗口必须大于短期窗口"
            return False, errors

    elif strategy_id == "macd":
        # MACD策略：快线周期必须小于慢线周期
        if params["fast_period"] >= params["slow_period"]:
            errors = errors or {}
            errors["slow_period"] = "慢线周期必须大于快线周期"
            return False, errors

    return True, None
```

async def get_categories_with_stats(self) -> List[Dict[str, Any]]:
    """
    获取分类及统计信息

    使用聚合管道一次性获取分类和策略数量
    """

                "name": 1,

            }
        },
        {

    ]

    cursor = self.category_collection.aggregate(pipeline)

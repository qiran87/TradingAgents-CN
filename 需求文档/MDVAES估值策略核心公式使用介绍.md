  📊 MDVAES 估值策略核心公式                                                                                                                                
                                                                                                                                                            
  一、整体计算流程                                                                                                                                          
                                                                                                                                                            
  ┌─────────────────────────────────────────────────────────────────┐
  │                     MDVAES 多锚点估值流程                        │
  ├─────────────────────────────────────────────────────────────────┤
  │                                                                 │
  │  1. EPS 预测获取 (分析师预测 + 历史外推)                         │
  │     │                                                           │
  │     ▼                                                           │
  │  2. 增长率计算 (对数最小二乘法回归)                               │
  │     ├── CAGR = (最新EPS / 起始EPS) ^ (1/年数差) - 1            │
  │     └── 增长率 = e^slope - 1                                    │
  │     │                                                           │
  │     ▼                                                           │
  │  3. 多锚点估值计算                                               │
  │     ├── PEG 估值: EPS × 增长率 × PEG基数 × 利率调整系数          │
  │     ├── PE 估值: EPS × 当前PE × 增长调整 × 0.8                  │
  │     ├── PB 估值: EPS × 1.5 (简化)                              │
  │     └── DCF 估值: 未来现金流折现 (使用 EPS预测年数)              │
  │     │                                                           │
  │     ▼                                                           │
  │  4. 加权平均: Σ(锚点估值 × 权重)                                │
  │     权重: PEG 40%, PE 30%, PB 15%, DCF 15%                    │
  │     │                                                           │
  │     ▼                                                           │
  │  5. 风险调整: 加权估值 × (1 - 风险调整幅度 × 风险系数)          │
  │     │                                                           │
  │     ▼                                                           │
  │  6. 估值区间: 内在价值 ± (内在价值 × (1-置信度) × 20%)          │
  │     │                                                           │
  │     ▼                                                           │
  │  7. 交易信号生成                                                 │
  │     └── 使用安全边际模式 或 估值区间模式                         │
  │                                                                 │
  └─────────────────────────────────────────────────────────────────┘

  ---
  二、核心公式详解

  公式 1：增长率计算（对数最小二乘法回归）

  ln(EPS) = slope × 年份 + intercept

  增长率 = e^slope - 1
  R² = 1 - (残差平方和 / 总平方和)

  公式 2：PEG 估值

  PEG_估值 = EPS × 增长率 × PEG基数 × 利率调整系数

  其中：
  利率调整系数 = 1 - 0.5 × 十年期国债收益率

  公式 3：历史 PE 估值

  PE_估值 = EPS × 当前PE × (1 + 增长率) × 0.8

  公式 4：DCF 估值（简化版）

  DCF_估值 = Σ(未来EPS_i / (1+折现率)^i) + 终值折现

  其中：
  - 未来EPS_i = EPS × (1 + 增长率)^i
  - 折现率 = 国债收益率 + 5%
  - 终值 = 第N年EPS × (1+永续增长率) / (折现率 - 永续增长率)
  - 永续增长率 = 3%

  公式 5：多锚点加权平均

  加权估值 = 0.4 × PEG估值 + 0.3 × PE估值 + 0.15 × PB估值 + 0.15 × DCF估值

  公式 6：风险调整

  风险调整系数 = {
      低风险: 0.5
      中风险: 1.0
      高风险: 1.5
  }

  调整后估值 = 加权估值 × (1 - 风险调整幅度 × 风险调整系数)

  公式 7：估值区间

  置信度 = min(R² - 风险惩罚, 0.95)
  风险惩罚 = 低风险:0, 中风险:0.1, 高风险:0.2

  估值区间宽度 = 调整后估值 × (1 - 置信度) × 20%
  估值下限 = 调整后估值 - 区间宽度
  估值上限 = 调整后估值 + 区间宽度

  公式 8：交易信号（两种模式）

  模式 A：估值区间模式
  if 价格 < 估值下限: 买入
  elif 价格 > 估值上限: 卖出
  else: 持有

  模式 B：安全边际模式
  买入阈值 = 内在价值 × 买入安全边际
  卖出阈值 = 内在价值 × 卖出安全边际

  if 价格 ≤ 买入阈值: 买入
  elif 价格 ≥ 卖出阈值: 卖出
  else: 持有

  三、用户参数详解

  参数: EPS预测年数
  在公式中的位置: DCF 估值中的预测周期
  默认值: 5年
  含义: 计算未来现金流时向前看多少年
  调整效果: ↑ 年数 ↑ DCF估值权重 ↑ 长期增长影响
  ────────────────────────────────────────
  参数: PEG基数
  在公式中的位置: PEG估值公式
  默认值: 1.0
  含义: PEG倍数的基准值，代表投资者愿意为增长率支付的倍数
  调整效果: ↓ 基数 ↓ 保守程度 ↑ PEG估值 ↓
  ────────────────────────────────────────
  参数: 风险调整幅度
  在公式中的位置: 风险调整公式
  默认值: 0.1 (10%)
  含义: 对估值进行风险折减的比例
  调整效果: ↑ 幅度 ↓ 调整后估值 ↑ 保守程度
  ────────────────────────────────────────
  参数: 重新估值频率(天)
  在公式中的位置: 回测循环逻辑
  默认值: 30天
  含义: 每隔多少天重新计算一次估值
  调整效果: ↓ 频率 ↑ 交易次数 ↑ 手续费 ↓ 频率 ↑ 反应速度
  ────────────────────────────────────────
  参数: 买入安全边际
  在公式中的位置: 安全边际买入阈值
  默认值: 0.8 (80%)
  含义: 价格达到估值的多少比例时买入
  调整效果: ↓ 比例 ↑ 买入难度 ↑ 安全度 ↑ 潜在收益
  ────────────────────────────────────────
  参数: 卖出安全边际
  在公式中的位置: 安全边际卖出阈值
  默认值: 1.2 (120%)
  含义: 价格达到估值的多少比例时卖出
  调整效果: ↑ 比例 ↓ 卖出难度 ↑ 持仓时间

  四、参数具体效果说明

  1️⃣  EPS预测年数 (forecast_years)

  影响环节： DCF 估值计算

  公式位置：
  # DCF 估值中
  for i in range(1, forecast_years + 1):
      forecast_eps = eps * ((1 + growth_rate) ** i)
      discounted_value = forecast_eps / ((1 + required_return) ** i)

  效果说明：

  ┌────────────┬─────────────────────────────────────────────────┬──────────────────────────┐
  │    设置    │                      效果                       │         适用场景         │
  ├────────────┼─────────────────────────────────────────────────┼──────────────────────────┤
  │ 3年        │ 短期预测为主，DCF估值权重降低，更关注近期表现   │ 高波动行业、科技股       │
  ├────────────┼─────────────────────────────────────────────────┼──────────────────────────┤
  │ 5年 (默认) │ 平衡短期和中期，标准估值周期                    │ 大部分成熟企业           │
  ├────────────┼─────────────────────────────────────────────────┼──────────────────────────┤
  │ 10年       │ 长期价值导向，DCF估值权重增加，适合稳定增长企业 │ 消费、公用事业等稳定行业 │
  └────────────┴─────────────────────────────────────────────────┴──────────────────────────┘

  ---
  2️⃣  PEG基数 (peg_base)

  影响环节： PEG 估值计算

  公式位置：
  peg_valuation = eps * growth_rate * peg_base * interest_adjustment

  效果说明：

  ┌────────────┬────────────────────────────────────────┬──────────────────────────────┐
  │    设置    │                  效果                  │           适用场景           │
  ├────────────┼────────────────────────────────────────┼──────────────────────────────┤
  │ 0.5        │ 保守估值，只愿意支付增长率一半的市盈率 │ 高风险、周期性、亏损边缘企业 │
  ├────────────┼────────────────────────────────────────┼──────────────────────────────┤
  │ 1.0 (默认) │ 标准估值，增长率=合理PE倍数            │ 正常增长企业                 │
  ├────────────┼────────────────────────────────────────┼──────────────────────────────┤
  │ 2.0        │ 激进估值，愿意为增长率支付2倍市盈率    │ 高成长、确定性强的企业       │
  └────────────┴────────────────────────────────────────┴──────────────────────────────┘

  举例：
  - EPS = 2元，增长率 = 20%
  - PEG基数 = 1.0 → PEG估值 = 2 × 0.2 × 1.0 = 40元
  - PEG基数 = 0.5 → PEG估值 = 2 × 0.2 × 0.5 = 20元
  - PEG基数 = 2.0 → PEG估值 = 2 × 0.2 × 2.0 = 80元

  3️⃣  风险调整幅度 (risk_adjustment)

  影响环节： 风险调整公式

  公式位置：
  risk_adjustment_factor = {
      "low": 0.5,      # 低风险企业
      "medium": 1.0,   # 中风险企业
      "high": 1.5      # 高风险企业
  }

  adjusted_valuation = weighted_valuation × (1 - risk_adjustment × risk_adjustment_factor)

  效果说明：

  ┌────────────┬────────────────┬────────────────┬────────────────┐
  │    设置    │ 高风险企业折减 │ 中风险企业折减 │ 低风险企业折减 │
  ├────────────┼────────────────┼────────────────┼────────────────┤
  │ 0          │ 0%             │ 0%             │ 0%             │
  ├────────────┼────────────────┼────────────────┼────────────────┤
  │ 0.1 (默认) │ 15%            │ 10%            │ 5%             │
  ├────────────┼────────────────┼────────────────┼────────────────┤
  │ 0.3        │ 45%            │ 30%            │ 15%            │
  └────────────┴────────────────┴────────────────┴────────────────┘

  举例：
  - 加权估值 = 100元，高风险企业，风险调整幅度 = 0.1
  - 调整后估值 = 100 × (1 - 0.1 × 1.5) = 100 × 0.85 = 85元

  5️⃣  买入安全边际 (margin_buy)

  影响环节： 安全边际买入阈值计算

  公式位置：
  buy_threshold = intrinsic_value × margin_buy

  if price <= buy_threshold:
      signal = BUY

  效果说明：

  ┌────────────┬──────────────────┬───────────────────────┐
  │    设置    │       含义       │ 示例 (内在价值=100元) │
  ├────────────┼──────────────────┼───────────────────────┤
  │ 0.5        │ 价格跌到50%才买  │ 50元买入              │
  ├────────────┼──────────────────┼───────────────────────┤
  │ 0.8 (默认) │ 价格跌到80%才买  │ 80元买入              │
  ├────────────┼──────────────────┼───────────────────────┤
  │ 0.95       │ 价格接近估值才买 │ 95元买入              │
  └────────────┴──────────────────┴───────────────────────┘

  权衡：
  - ↓ 边际 ↑ 安全度 ↑ 潜在收益 ↓ 买入机会
  - ↑ 边际 ↓ 安全度 ↓ 买入机会 ↑ 但风险更高

  六、Gemini推荐行业参数
  “综合多因子估值模型”
专家建议根据公司的生命周期和行业属性调整权重：
| 公司类型 | 核心锚点 (建议权重) | 逻辑 |
| :--- | :--- | :--- |
| 高成长股 (AI/芯片) | PEG (50%) + DCF (40%) | 关注未来现金流和增长溢价 |
| 成熟蓝筹 (消费/电力) | PE (60%) + DCF (20%) + 股息率 (20%) | 盈利稳定性是关键 |
| 重资产/周期 (银行/钢铁) | PB (70%) + PE (30%) | 账面资产的安全边际最重要 |

行业类型	PEG (增长)	PE (盈利)	PB (资产)	DCF (现金)	设置逻辑
重资产/金融 (银行/地产/钢铁)	5%	25%	60%	10%	资产是底线。只要资产不减值，PB就是最硬的锚点。
成熟消费/公用事业 (电力/食品)	10%	50%	10%	30%	利润稳、现金流好。主要看盈利能力和分红潜力。
高成长科技 (AI/芯片/软件)	50%	10%	5%	35%	现在的利润不重要，未来的增长(G)和自由现金流才是核心。
通信运营 (中国联通/移动)	10%	30%	30%	30%	兼具资产属性和现金流属性，权重分配较均衡。

保险 (中国平安/寿险)	P/EV (70%) + PE (20%) + PB (10%)	EV (内含价值) 是保险股的唯一真理。保险合同是长期的，当期利润极易受会计准则干扰，必须看 EV。
通信运营 (联通/移动)	EV/EBITDA (50%) + 股息率 (30%) + PE (20%)	通信业有巨大的折旧支出。EBITDA 剔除了折旧影响，更能反映真实经营现金能力；同时这类公司已进入收割期，**分红（股息率）**是股价的压舱石。
互联网平台 (美团/腾讯)	DCF (50%) + PE (30%) + PS (20%)	互联网卖的是“流量”和“垄断预期”。DCF 衡量未来变现能力，PS 用于衡量尚未完全盈利的业务线（如外卖、云服务）。
生物医药 (创新药)	DCF (80%) + Pipeline估值 (20%)	创新药可能连续 5 年亏损，PE/PB 完全失效。估值全靠对研发管线（Pipeline）未来获批后的现金流折现。
半导体设备/材料	PEG (40%) + PS (40%) + PE (20%)	高研发投入导致净利波动大。PS 衡量市场占有率，PEG 衡量高增长下的溢价合理性。
